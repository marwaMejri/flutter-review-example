# Notely releases

The release notes of Notely, a notes app, in a Flutter app.

This app is the test project of
[flutter-review-agent](https://github.com/marwaMejri/flutter-review-agent): each
pull request is reviewed by the agent.

## Run

```
flutter pub get
flutter run
```

## Architecture

The rules are in [CONVENTIONS.md](CONVENTIONS.md): one folder for each feature,
with `data`, `domain` and `presentation` layers.
